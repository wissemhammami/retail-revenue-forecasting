Rolling-origin backtest: 28-day horizon, weekly origins, 23 development folds for model selection and 11 untouched test folds (Sep–Nov 2011).

Limitations

  • Only 373 days of history, so yearly seasonality is not modelled; the December forecast extends the weekly pattern and known closures.
  • The 11 test origins use overlapping 28-day windows, so the gain over the baseline is less certain than the headline number suggests.
  • All models under-forecast on the test period (bias of about −£4.8k per day).
  • Intervals are calibrated on development residuals; out-of-sample coverage has not been verified yet.
